Davi Lucas — A Grande Aventura 3D
Desenvolvido em HTML5 + Three.js
Protagonista: Davi Lucas (10 anos)
Irmãos na história: Daniel Henrique e Ana Sofia

📚 BIBLIOTECAS

Three.js — Licença MIT
threejs.org

🎨 ASSETS 3D

Nenhum modelo 3D externo foi utilizado.
Todos os personagens, cenários, inimigos, obstáculos e efeitos são gerados proceduralmente no código usando geometrias primitivas do Three.js (esferas, cilindros, caixas, torus, cones).
Isso garante uso livre, funcionamento offline e licença totalmente permissiva.

🎵 ÁUDIO

Sons gerados via Web Audio API (osciladores sintetizados). Nenhum arquivo de áudio externo utilizado.

🖼 TEXTURAS

Nenhuma textura externa utilizada. Materiais procedurais.
